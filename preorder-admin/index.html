Токен GitHub

Ціни зберігаються в репозиторії сайту, тому для запису потрібен токен GitHub (вводиться один раз, браузер його запам'ятає; той самий, що для «Ціни Prom»). Вставте токен з доступом до репозиторію companyyyy/avtonomka_site (Contents: Read and write):

Наявність і ціна «на сайті» - з сайту (постачальник), їх тут не змінити. Впишіть ціну під замовлення - у товару з'явиться окрема сторінка «під замовлення» і пропозиція в Google Merchant. Ціна має бути нижчою за ціну на сайті, інакше пропозиція не показується. Ціну можна вписати в доларах - гривні порахуються за курсом угорі, а зміна курсу перерахує всі доларові ціни (поле «грн» у такого товару сіре). Без доларів - вписуйте гривні, як раніше. Строк - через скільки днів товар буде у клієнта (порожньо = 14). Щоб прибрати пропозицію, зітріть ціну. Після збереження сайт оновиться приблизно за 2–3 хвилини.
