Відсотки по категоріях

Порожнє поле - діє індивідуальний відсоток партнера, а без нього - загальний. 0 - за цю категорію не нараховується.

Пріоритет ставки: товар → категорія → індивідуальна партнера → загальна. Ставки фіксуються в нарахуванні на момент замовлення - зміни тут не перераховують уже створені нарахування.
